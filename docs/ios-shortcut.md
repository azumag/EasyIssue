# iPhone / iPadの共有シートからEasyIssueを開く

初期版ではiOSの「ショートカット」を共有シートとEasyIssueの橋渡しにします。

## 作成手順

1. 「ショートカット」アプリで新しいショートカットを作る
2. 名前を`EasyIssueに送る`にする
3. 詳細から「共有シートに表示」を有効にする
4. 受け入れる入力を「URL」と「テキスト」に絞る
5. 「URLエンコード」アクションを追加し、入力を「ショートカットの入力」にする
6. 「テキスト」アクションを追加し、次の形式にする

```text
https://YOUR-EASYISSUE.example.com/share?text=[URLエンコード済みのテキスト]
```

7. 「URLを開く」アクションを追加し、直前のテキストを開く
8. 保存する

これでX、Chrome、Safariなどの共有シート下部に`EasyIssueに送る`が表示されます。共有内容にURLが含まれていれば、EasyIssueが本文と参照元へ分離します。

## 補足

- デプロイ先URLを変更した場合は、ショートカット内のURLも変更します。
- 共有元がタイトルを渡さない場合、EasyIssueは共有テキストの先頭行またはURLのホスト名を仮タイトルにします。
- 初回はGitHubログインが必要ですが、共有内容はOAuth完了後までURLに保持されます。
